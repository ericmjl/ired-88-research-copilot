# Live demo skeletons

Empty twins of the analysis notebooks, for presenting the demo live.

- Same questions, same filenames, **no code**: just the question cells,
  imports, and step hints as comments.
- Build the analysis cell by cell in front of the audience; the filled
  versions one directory up are the answer key if you need to peek.
- Run with `pixi run marimo edit notebooks/live/` (or
  `uvx marimo edit --sandbox notebooks/live/`).

Tip: marimo has a presentation mode (the appbar button, or `marimo run`
for a read-only view) that hides code and shows outputs only -- handy once
a notebook is filled and you want to walk the crowd through results.
