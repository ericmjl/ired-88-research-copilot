# IRED-88 Research Copilot

A single repo where DMS data, a literature knowledge base, a crystal
structure, and structure prediction answer one scientific question together,
in marimo notebooks.

Start with [the notebooks](https://github.com/ericmjl/ired-88-research-copilot/tree/main/notebooks)
and the [README](https://github.com/ericmjl/ired-88-research-copilot).
